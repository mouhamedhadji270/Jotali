# Jotali - Site d'Actualité

## Description

**Jotali** est un site d'actualité développé avec PHP et exécuté sur un serveur Apache via XAMPP. Il permet la gestion, la publication et la diffusion d'articles d'actualité à travers une interface web.

## Fonctionnalités

* Gestion des articles (ajout, modification, suppression)
* Affichage des actualités
* Gestion des catégories
* Gestion des utilisateurs et des administrateurs
* Connexion à une base de données MySQL
* API et traitements backend en PHP

## Technologies utilisées

* PHP
* MySQL
* Apache (XAMPP)
* HTML
* CSS
* JavaScript

## Installation

1. Cloner le dépôt :

```bash
git clone https://github.com/papecheikhmbaye64-afk/Backend.git
```

2. Copier le projet dans le dossier `htdocs` de XAMPP.

3. Démarrer **Apache** et **MySQL** depuis le panneau de contrôle XAMPP.

4. Importer la base de données dans **phpMyAdmin**.

5. Accéder au projet via :

```text
http://localhost/Backend
```
